VIDEO IMAGE STUDIO 0.3.23 — NHẬN FILE TẢI XUỐNG, GIAO DIỆN 10 DÒNG

CẬP NHẬT:
Đóng Studio cũ. Chạy CAP_NHAT_BAN_CU.bat trong bản này và chọn thư mục đã cài. Bộ cập nhật sao chép cả download_watch.py. Tải lại tiện ích trong edge://extensions, tải lại tab ChatGPT, ghép mã mới nếu dùng chức năng gửi prompt. Ctrl+F5 Studio, kiểm tra Bản 0.3.23. Giữ thư mục projects.

THIẾT LẬP NHẬN ẢNH:
1. Tạo một thư mục riêng, ví dụ D:\AnhChatGPT.
2. Trong Studio chọn thư mục đó ở thanh Thư mục ảnh tải về, bấm Bật nhận ảnh.
3. Khi bấm Download trong ChatGPT, lưu ảnh vào đúng thư mục này. Có thể bật tùy chọn hỏi nơi lưu file của trình duyệt.
4. Ảnh có sẵn trước lúc bật nhận được bỏ qua; chỉ file tải mới được theo dõi.
5. Khi mở lại Studio, bật nhận ảnh lại. Đường dẫn thư mục được nhớ; phần theo dõi không tự bật sau khởi động để tránh nhập nhầm file cũ.

SỬ DỤNG:
- Khi yêu cầu đã gửi, dòng chuyển sang Chờ tải file. Studio không dò ảnh trên trang ChatGPT để hoàn thành nữa.
- Bạn bấm Download trong ChatGPT. File hoàn chỉnh, ổn định ít nhất 3 giây và đọc được ảnh mới được lưu vào Studio. Khi đó hiện ảnh, báo Hoàn thành, xóa lỗi cũ và dừng đồng hồ.
- Ảnh cũ đang báo lỗi: tab Tiến trình và kết quả, bấm Nhận file tiếp theo ở đúng dòng rồi tải ảnh đó về thư mục đã chọn.
- Nếu nhiều file mới cùng xuất hiện: không tự gắn nhầm. Bấm Chọn file mới ở đúng dòng và chọn tên file.
- Một lần chỉ nhận tự động cho một dòng. Nhận xong mới chuyển sang dòng tiếp theo.
- Chức năng gửi prompt qua tiện ích vẫn cần kết nối nếu sử dụng. Nhận file tải trên máy không cần ChatGPT API hoặc quyền đọc kết quả trên trang.
- Có thể dùng Nhập ảnh cho các file đã tải trước khi bật theo dõi.

GIAO DIỆN:
Hai tab Tạo ảnh và Tiến trình và kết quả nằm cạnh tên VIDEO IMAGE STUDIO. Khung 10 dòng co theo chiều cao màn hình desktop; trạng thái một dòng, không đẩy dòng kế tiếp. Bấm trạng thái để xem lỗi chi tiết. Nội dung dài cuộn bên trong từng ô. Màn hình hẹp dùng bố cục đáp ứng.

KIỂM TRA:
Đã kiểm thử file cũ, file tải dở, file ổn định, tránh nhập lặp, nhiều file cần lựa chọn, hoàn thành sau lưu ảnh; khởi tạo giao diện đủ 10 dòng và lỗi dài không nằm trong nội dung trạng thái. Chưa kiểm thử render trên trình duyệt Windows thực tế của người dùng.
