# VIDEO IMAGE STUDIO Web Bridge

1. Mở Chrome hoặc Edge tại trang extensions và bật Developer mode.
2. Chọn **Load unpacked** và chọn chính thư mục `web_extension`.
3. Mở tab ChatGPT, đăng nhập tài khoản của bạn.
4. Mở web VIDEO IMAGE STUDIO, sao chép mã ghép.
5. Bấm biểu tượng tiện ích, dán mã ghép và bấm **Ghép tiện ích**.

Tiện ích chỉ đọc ô nhập và phản hồi trong tab ChatGPT bạn đang mở để gửi lần lượt từng prompt. Tiện ích không yêu cầu hay đọc mật khẩu/cookie ChatGPT.
